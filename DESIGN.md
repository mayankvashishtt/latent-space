# LATENT SPACE — Design & Syllabus Map

**Goal:** take a person who knows nothing about AI and have them personally OPERATE every core
mechanism — so "neuron", "attention", "training", "reward hacking" are things they've DONE.

## Session flow
TITLE → ORIGIN STORY (once, 5 pages: recipe problem → copy the brain → the math neuron → your
journey) → JOURNEY MAP (4 worlds · 9 chambers · stars) → HUB corridor → chambers in order →
world complete = ⭐ → 4⭐ unlock IX Output Head → TOKEN EMITTED finale. ~90–105 min total.

## The 7-layer teaching stack (every chamber)
1. Intro panel — WHY this room exists / what you'll do / watch for
2. NOVA + BIT step dialogue — say → player does → notice → next (typewriter + blips; V = TTS)
3. TASK card — exact next move, always on screen
4. 📘 Lessons (22 total) at moment-of-impact — saved to the L log
5. The mechanic itself — concept made physical
6. Codex recap + link to the full lecture notes
7. Safety nets — H auto-solve/show, ◆ waypoint, breadcrumbs, stuck nudges, M map, L log

## Chambers
- W1 ⭐ — I · THE LEARNING MACHINE (~15–20m): neuron=one cut (weights/bias, live decision-region
  glow) → XOR impossibility, 1969, hidden layers (two-wall corridor) → gradient descent valley
  (gradient arrow, LR keys 1/2/3, compute budget, local minima, momentum). 6 lessons. → week-02
- W2 ⭐ — II · TOKENIZER (~8–10m): hand-run BPE; strawberry monoliths (perception vs stupidity).
  → week-03 · III · EMBEDDING SPACE (~8–10m): file words by meaning; KING−MAN+WOMAN ride;
  date-blob foreshadow. → week-03/s06 · IV · ATTENTION (~10–12m): 1.00 budget routing; sentence
  mutates tired→wide; causal glass; KV cache choice. → week-04
- W3 ⭐ — V · ARCHIVE (~10–12m): semantic search fails on a date (real 0.551/0.548 distances);
  grep; hybrid; context-rot corridor + shredders. → week-09/10 · VI · AGENT FOUNDRY (~8–10m):
  you write the robot's tool description; think-act-observe loop; errors as messages. → week-08/17
- W4 ⭐ — VII · REWARD PEAKS (~8–10m): touch-hack, proximity-camp, basket-verified reward; GRPO
  race. → week-14/15 · VIII · GAUNTLET (~8–10m): prompt injection by a wall sign; filter loses to
  the friendly attack; revoking the tool wins. → s04
- FINAL — IX · OUTPUT HEAD (4⭐, ~8–10m): five no-hint remix rooms + softmax gate with
  temperature dial; TOKEN EMITTED. → s07
